# Chapter 21

A cinematic, photo-free 21st birthday website built with HTML, CSS and vanilla JavaScript.

## Deploy to GitHub Pages
1. Upload `index.html`, `style.css`, `script.js`, and the `music` folder to your repository.
2. Put your own MP3 at `music/music.mp3`.
3. Edit the `birthdayConfig` object at the top of `script.js`.
4. Enable GitHub Pages from the repository settings.

No photographs are required.
